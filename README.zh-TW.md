### 🔮 全新推出：INCY Config Tool (終極 PWA)

除了全域的轉換系統，目前專案加入了一套 **專屬於行動裝置的獨立編輯環境 (IDE)**，能夠讓您在各種情境下手動修剪 `incy://` 以及 `happ://` 的分流設定檔。

* 📱 **零外部依賴 & PWA：** 僅由 1 個 HTML 檔案組成，完全無外部庫。支援 100% 離線執行（可如原生應用程式般添加到手機主畫面）。
* 🪄 **INCY-MINI 壓縮演算法：** 獨有壓縮技術，將訂閱長度激減（5倍以上），完美避開 Telegram / WhatsApp 訊息被中途截斷的限制 (並從內部自動解壓縮)。
* 🚀 **深度連結直達 (Deep-Link)：** 修改好配置檔後，可直接一鍵導向您的手機代理端 APP 完成匯入。
* 🧠 **行動版智慧編輯器：** 與 VS Code 相似的自動縮排功能，精準識別 JSON 語法錯誤並自動捲動對齊，支援一站式復原 (Undo) 以及設定檔修改歷史。

### 🔥 17.05 ULTRA 版本的全新亮點？ (極致高並發)

* 🌐 **新增協議廣泛支援：** 全面覆蓋 **VMess, Hysteria2 (hy2), Shadowsocks (SS), 以及 ShadowsocksR (SSR)** 的自動解析。
* 🚀 **極限效能解析 (HighLoad)：** 引入非同步加載以及 `Set` 字典機制。透過 DOM 虛擬化，能在毫秒級單位清洗和去重 **250,000+** 筆節點且不卡死瀏覽器。
* 🛡️ **YAML 裝甲淨化器：** 工業級過濾標準。腳本自動捨棄垃圾數據（如不可見的 ASCII 字元、偽造的 `2022-blake3` 協定及空白密碼等），保障在 Mihomo 內 100% 無痛導入。
* ⚙️ **徹底解決超時 (Timeouts)：** 嚴格遵循 Mihomo 規範重寫 YAML 生成器 (內含 `alpn`、`skip-cert-verify: true` 及 針對俄區改良後的 Fake-IP DNS)。
* 🎨 **全新 UI 與功能：** 新增明暗雙重主題記憶、以及能直接將 RAW 來源 (Pastebin / GitHub) 打包至 `proxy-providers` 區塊的「訂閱切換鈕」。

### 🛡️ 其它審查繞過與代理輔助工具 (DPI Bypass)

*如果標準的 VPN 通訊協定遭逢 ISP 嚴酷的防火牆封鎖與包檢測干擾，請嘗試以下深度反制工具:*

* [Zapret](https://github.com/bol-van/zapret) — 系統級，超級強大且高自定義的 DPI 欺騙與逃脫方案。
* [Zapret2](https://github.com/bol-van/zapret2) — 由 `bol-van` 進行實驗與維護的新一代黑科技分支。
* [Zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) — 以 Zapret 為基礎，立刻解決 Discord 與 Youtube 無法連線的腳本封裝。
* [ByeByeDPI](https://github.com/romanvht/ByeByeDPI) — 針對 Windows 環境且具備深厚穩定性的老牌避牆好手。
* [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) — 將 Telegram 以 WebSockets 協定反向處理，讓您在嚴酷的封鎖環境下依然保持訊號聯通。
