### 🔥 v17.05 ULTRA 版本有什麼新功能？ (The HighLoad Perfection)

* 👑 **Throne 整合：** 新增了對為現代桌面客戶端 Throne 建立和託管加密路由設定檔 (`throne://`) 的支援。
* 🌐 **全球協定擴展：** 增加了對 **VMess、Hysteria2 (hy2)、Shadowsocks (SS) 和 ShadowsocksR (SSR)** 的全面解析支援。
* 🚀 **極致效能 (HighLoad)：** 實作了非同步分塊和 `Set` 字典。DOM 虛擬化允許在幾毫秒內載入並清理超過 **250,000 個節點** 的重複項，而不會導致瀏覽器卡頓。
* 🛡️ **穿甲彈級 YAML 清理器：** 工業級准入控制。腳本會自動清除公共列表中的垃圾資料（不可見的 ASCII 字元、偽造的 `2022-blake3` 密碼、空密碼），並保證 100% 穩定匯入 Mihomo。
* ⚙️ **戰勝超時：** YAML 產生器被重寫以符合嚴格的 Mihomo 標準（添加了 `alpn`、`skip-cert-verify: true`、`servername` 並改進了 Fake-IP DNS）。
* 🎨 **全新 UI/UX：** 獨立的淺色/深色主題，帶有獨立的顏色保存功能，以及一個 **「訂閱模式」開關**，用於將 RAW 連結（Pastebin/GitHub）直接嵌入到 `proxy-providers` 區塊中。

### 🚦 路由內部是什麼（規則）

可靠的「外科手術式」分割隧道，使所需資源無延遲起飛，而被屏蔽的資源透過代理打開。

<table width="100%">
<tbody>
<tr>
  <td>🔴 <b>BLOCK (攔截)</b></td>
  <td>廣告、追蹤器、遙測資料（節省伺服器流量和設備資源）</td>
</tr>
<tr>
  <td>🟢 <b>DIRECT (直連)</b></td>
  <td>本地供應商、大學、銀行、政府服務（極低的延遲，不會因可疑 IP 導致銀行封號）</td>
</tr>
<tr>
  <td>🔵 <b>PROXY (透過 VPN)</b></td>
  <td>YouTube、Instagram、ChatGPT、外國 CDN 以及所有其他被屏蔽的流量</td>
</tr>

### 🛡️ 替代工具 (DPI Bypass & Proxy)

*如果標準 VPN 協定被營運商或 TSPU 完全封鎖，請使用本地深度封包檢測繞過或專用代理隧道：*

* [Zapret](https://github.com/bol-van/zapret) — 用於在系統層面進行深度 DPI 繞過的最強大和靈活的工具。
* [Zapret2](https://github.com/bol-van/zapret2) — 來自 `bol-van` 的強大繞過腳本的更新和實驗分支。
* [Zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) — 針對特定流行服務進行了優化和配置的現成繞過腳本。
* [ByeByeDPI](https://github.com/romanvht/ByeByeDPI) — 在 Windows 上本地運行的經過驗證的經典解決方案。
* [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) — 透過 WebSockets 代理 Telegram 的工具（保證即時通訊軟體在嚴重封鎖下穩定運行）。
