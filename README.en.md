### 🔥 What's New in v17.00 ULTRA?

- 🚀 **Extreme Parser Engine:** Full code optimization for handling **10,000+ nodes** simultaneously. Smooth UI even with massive data volumes.
- 🌍 **ULTRA Localization:** Deep support for 6 languages. Interface and system notifications are now fully adapted for each region.
- 🛡️ **QuotaGuard System:** Intelligent protection against browser memory overflow. Work with any config size without crashing the tab.
- 🧠 **Smart Duplicate Filter:** Automatic server comparison via IP:Port pairs. The program cleans up junk and duplicates, leaving only unique nodes.
- 🛠️ **Refined Diagnostics:** Updated event logger and fixed syntax errors for flawless stability.
