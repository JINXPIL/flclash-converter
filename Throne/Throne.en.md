# 👑 Throne Routing Profile (NekoRay / NekoBox)

This folder contains a ready-made routing profile for clients based on the Sing-box / Xray core (**Throne, NekoRay, NekoBox**). 
It is configured for comfortable and secure censorship bypass:
* 🟢 **Local/Russian services** work directly (without VPN).
* 🔵 **Blocked sites** open via proxy.
* 🔴 **Garbage traffic** (ads, tracking) is blocked at the program level.

---

## 📥 How to install the profile

1. Open the `Throne_INSTALL.DEEPLINK` file in this folder.
2. Copy the entire long string that starts with `throne://route/...` *(select it and press Ctrl+C)*.
3. Open the **Throne** (or NekoRay) program on your PC.
4. Go to the top menu: **Preferences ➔ Routing**.
5. Click the **Import** (or *Import from Clipboard*) button and paste the copied link.
6. Click **OK**. Done! 🎉
