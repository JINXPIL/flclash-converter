### 🔮 新增：INCY Config Tool (终极 PWA)

除了全局转换器外，本项目如今提供一个 **专为移动设备设计的独立开发环境 (IDE)**，能够让您随时随地对 `incy://` 以及 `happ://` 分流配置文件进行外科手术般的修改。

* 📱 **零依赖 & PWA：** 仅由 1 个 HTML 文件组成，无外部库。支持 100% 离线使用（可添加至主屏幕作为原生 APP）。
* 🪄 **INCY-MINI 封装：** 独有的算法将链接压缩（5 倍以上），完美避开 Telegram / WhatsApp 的消息长度限制 (并在内部自动解压)。
* 🚀 **深度链接直达 (Deep-Link)：** 编辑好配置文件后，一键唤起系统代理客户端并极速导入配置。
* 🧠 **移动端智能编辑器：** 模拟 VS Code 的自动智能缩进，自带错误定位滚动追踪，支持一站式撤销 (Undo)、代码美化及配置版本历史。

### 🔥 版本 17.05 ULTRA 的新特性 (高并发完美版)

* 🌐 **全局协议扩充：** 新增全方位支持解析 **VMess, Hysteria2 (hy2), Shadowsocks (SS), 及 ShadowsocksR (SSR)**。
* 🚀 **极致性能 (HighLoad)：** 引入异步分块与 `Set` 字典机制。利用 DOM 虚拟化，可以瞬间加载并去重 **250,000+ 个节点** 而不会使浏览器卡死。
* 🛡️ **穿甲级 YAML 净化器：** 工业级准入策略。脚本自动清理公共池里的垃圾数据（如隐形 ASCII 字符、虚假的 `2022-blake3` 伪加密、空白密码），确保在 Mihomo 中 100% 毫无错误地导入体验。
* ⚙️ **攻克超时 (Timeouts) 难题：** YAML 生成器严格遵从 Mihomo 规范进行了重写（追加了 `alpn`、`skip-cert-verify: true`、`servername` 以及改良后的俄区 Fake-IP DNS）。
* 🎨 **全新 UI/UX：** 独立的日间/夜间模式自动记忆，新增 **订阅模式 (Subscription Mode)** 开关，可直接将 RAW 链接源 (Pastebin / GitHub) 嵌入至 `proxy-providers` 块中。

### 🛡️ 其他审查绕过与代理工具 (DPI Bypass)

*如果常规 VPN 协议遭到网络运营商完全封锁屏蔽，请试试以下这些绕过深度包检测（DPI）的反封锁防线工具：*

* [Zapret](https://github.com/bol-van/zapret) — 极其强大，具备难以置信的灵活度，系统级实现 DPI 欺骗方案。
* [Zapret2](https://github.com/bol-van/zapret2) — 由 `bol-van` 持续维护和升级的黑科技分支实验版。
* [Zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) — 基于前者，针对 Discord 和 YouTube 等网络专门优化的免配置脚本。
* [ByeByeDPI](https://github.com/romanvht/ByeByeDPI) — 面向 Windows 用户最普及和经典的抗 DPI 脱困组件。
* [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) — 一款使用 WebSockets 在极重度审查区域保障 Telegram 连接顺畅传输的强力代理。
