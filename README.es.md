### 🔮 Novedad: INCY Config Tool (PWA Definitiva)

Además de la conversión masiva, el proyecto ahora proporciona **un IDE móvil altamente optimizado** para modificaciones sobre la marcha a perfiles de enrutamiento muy pesados tipo `incy://` y `happ://`.

* 📱 **Cero dependencias y formato PWA:** Es tan solo un archivo HTML local. Funciona completamente fuera de línea y puede instalarse como una app nativa en el inicio.
* 🪄 **Envoltorio INCY-MINI:** ¡Innova mediante compresión local! Permite tomar enlaces densos, dividiendo su peso x5 para compartirlos por plataformas recortadas (como WhatsApp/Telegram).
* 🚀 **Enlace profundo directo (Deep-Link):** Abre sus cambios rápidamente dirigiendo al programa base pulsando un botón, ¡libre de la engorrosa gestión en el portapapeles!
* 🧠 **Editor Inteligente:** Indentado automatizado similar al de VS Code, seguimiento dinámico de errores JSON y restablecimiento de variables (Undo).

👉 **[Ejecutar INCY Config Tool](https://jinxpil.github.io/flclash-converter/INCY_Tool.html)**

### 🔥 ¿Qué hay de nuevo en la Ultra 17.05?

* 🌐 **Protocolos ampliados:** Soporte absoluto para nodos **VMess**, cifrados super veloces en **Hysteria2**, junto a **Shadowsocks (SS/SSR)**.
* 🚀 **Aceleración para cargas pesadas:** Algoritmo avanzado que no congela el navegador mediante DOM virtual y chunks. Elimine duplicados de más de **250,000 servidores** en tan solo unos milisegundos.
* 🛡️ **Sanitizador YAML para Mihomo:** Una fuerte purga estructural omite perfiles públicos corruptos, corrigiendo automáticamente los ciphers estáticos obsoletos.
* 🎨 **Mejora Integral:** Inclusión del famoso **Botón Sub-Mode**, posibilitando la recolección RAW a gran escala.

### 🛡️ Herramientas alternativas (Evasión de DPI y Proxy)

*Si los protocolos de VPN están bloqueados activamente mediante Inspección Profunda de Paquetes (DPI), puedes utilizar estas contramedidas extremas recomendadas:*

* [Zapret](https://github.com/bol-van/zapret) — Solución suprema y ampliamente personalizable para anular DPI a nivel root en el sistema.
* [Zapret2](https://github.com/bol-van/zapret2) — Versiones actualizadas de componentes experimentales DPI para un rendimiento robusto.
* [Zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) — Secuencias de script automatizadas, especializadas en el uso perfecto de YouTube y Discord.
* [ByeByeDPI](https://github.com/romanvht/ByeByeDPI) — Clásico enfoque verificado localmente por comandos rápidos diseñado para sortear censuras en PC.
* [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) — Red protectora para tunelizar Telegram desde WebSockets sin desconexiones prolongadas.
