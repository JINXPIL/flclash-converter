### 🔮 Nuevo: INCY Config Tool (Ultimate PWA)

Además del convertidor global, el proyecto cuenta con un **entorno de desarrollo integrado (IDE) especial e independiente para dispositivos móviles**, diseñado para la edición quirúrgica de perfiles de enrutamiento `incy://` y `happ://` directamente "sobre la marcha".

* 📱 **Zero-Dependency & PWA:** Consta de 1 archivo. No utiliza bibliotecas externas. Funciona 100% localmente incluso sin Internet (se puede agregar a la pantalla de inicio del teléfono como una aplicación nativa).
* 🪄 **Envoltura INCY-MINI:** Algoritmo sistémico único de compresión de enlaces (más de 5 veces) para eludir los límites de longitud de mensajes de Telegram/WhatsApp (con posterior autodescompresión).
* 🚀 **Deep-Link Directo:** Capacidad de iniciar el perfil modificado directamente desde el navegador en el cliente con un solo toque.
* 🧠 **Editor Móvil Inteligente:** Sangría automática (como en VS Code), localizador de errores de sintaxis JSON con desplazamiento automático, interceptor de deshacer, administrador de formato e historial completo de cambios de perfil.

👉 **[Iniciar INCY Config Tool](https://jinxpil.github.io/flclash-converter/INCY_Tool.html)**

### 🔥 ¿Qué hay de nuevo en la v17.05 ULTRA? (The HighLoad Perfection)

* 👑 **Integración con Throne:** Se agregó soporte para crear y alojar perfiles de enrutamiento cifrados (`throne://`) para el moderno cliente de escritorio Throne.
* 🌐 **Expansión Global de Protocolos:** Se agregó soporte de análisis completo para **VMess, Hysteria2 (hy2), Shadowsocks (SS) y ShadowsocksR (SSR)**.
* 🚀 **Rendimiento Extremo (HighLoad):** Se implementó fragmentación asincrónica y diccionarios `Set`. La virtualización del DOM permite cargar y eliminar duplicados de **más de 250,000 nodos** en milisegundos sin congelar el navegador.
* 🛡️ **Desinfectante YAML Antiblindaje:** Face-Control industrial. El script destruye automáticamente la basura de las listas públicas (caracteres ASCII invisibles, cifrados falsos `2022-blake3`, contraseñas vacías) y garantiza una importación 100% estable en Mihomo.
* ⚙️ **Victoria Sobre los Timeouts:** El generador YAML se reescribe según los estrictos estándares de Mihomo (se agregaron `alpn`, `skip-cert-verify: true`, `servername` y Fake-IP DNS mejorado).
* 🎨 **Nuevo UI/UX:** Temas claro/oscuro separados con guardado de color independiente y un **interruptor de "Modo de Suscripción"** para la inserción directa de enlaces RAW (Pastebin/GitHub) en el bloque `proxy-providers`.

### 🚦 Qué hay dentro del enrutamiento (Reglas)

Túnel dividido "quirúrgico" confiable para que los recursos necesarios vuelen sin demoras y los bloqueados se abran a través del proxy.

<table width="100%">
<tbody>
<tr>

### 🛡️ Herramientas Alternativas (DPI Bypass & Proxy)

*Si los protocolos VPN estándar están completamente bloqueados por el operador o TSPU, use la evasión local de inspección profunda de paquetes o túneles proxy especializados:*

* [Zapret](https://github.com/bol-van/zapret) — La herramienta más potente y flexible para el desvío profundo de DPI a nivel del sistema.
* [Zapret2](https://github.com/bol-van/zapret2) — Rama actualizada y experimental de potentes scripts de desvío de `bol-van`.
* [Zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) — Scripts de evasión preconfigurados y optimizados para servicios populares específicos.
* [ByeByeDPI](https://github.com/romanvht/ByeByeDPI) — Solución clásica comprobada para ejecución local en Windows.
* [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) — Herramienta para proxy de Telegram a través de WebSockets (garantiza el funcionamiento estable del mensajero bajo bloqueos severos).
