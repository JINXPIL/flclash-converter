# ⚡ Network Builder v10.0 Ultimate (Omni-Core)

Универсальный браузерный комбайн для конвертации, тестирования и управления прокси-конфигурациями. Настоящий швейцарский нож для обхода блокировок и работы с сетями.

Работает на **100% в браузере (Client-side)**. Никакие данные не отправляются на сторонние серверы, всё обрабатывается локально на вашем устройстве.

🌐 **[Live Demo: Открыть Network Builder](https://jinxpil.github.io/flclash-converter/)**

---

## 🔥 Главные фичи (v10.0)

* **Omni-Парсер:** Понимает как сырые ссылки-подписки, так и сложные `JSON` профили (из Nekobox, Xray, v2rayNG). Автоматически вытаскивает скрытые узлы из чужих конфигов.
* **Drag-and-Drop:** Просто перетащите `.txt` или `.json` файл в окно браузера.
* **Stealth-Пинг:** Встроенная проверка серверов на доступность. Умный алгоритм распознает защищенные протоколы (Reality, UDP) и помечает их как `🛡️ Stealth`, а не `Err`.
* **Smart Clean (Умная очистка):** Удаление всех нерабочих (мертвых) узлов в один клик.
* **Geo-IP Флаги 🌍:** Автоматическое определение страны сервера по IP и добавление красивых эмодзи-флагов (🇩🇪, 🇳🇱, 🇺🇸) к названиям узлов.
* **Массовое переименование:** Задайте префикс, и скрипт красиво пронумерует все ваши 100+ серверов за секунду.
* **Встроенный редактор кода:** Вносите правки в сгенерированный YAML/JSON прямо на странице перед скачиванием.
* **Трекер версий Mihomo:** Интеграция с GitHub API в реальном времени показывает актуальные Stable и Alpha версии ядра.

## 🔌 Поддерживаемые протоколы (Inbound)

Скрипт умеет распаковывать и обрабатывать 12 видов протоколов:
* `VLESS` (включая XTLS Reality)
* `VMess`
* `Trojan`
* `Hysteria2` (hy2)
* `Shadowsocks` (SS)
* `ShadowsocksR` (SSR)
* `WireGuard` (wg)
* `TUIC`
* `NaïveProxy`
* `SSH`
* `Socks5` / `HTTP`

## 📦 Форматы экспорта (Outbound)

Конвертер собирает готовые рабочие профили под разные клиенты:

1.  **📱 FlClash YAML (Mobile / PC)** — Готовый профиль с настроенным TUN, маршрутизацией, DNS и фильтрацией рекламы.
2.  **🌐 FlClash YAML (Router)** — Специальная версия для роутеров (Keenetic, OpenWRT) без конфликтов с TUN (tproxy/redir).
3.  **📦 Sing-box (JSON)** — Эталонный формат `outbounds` для ядра Sing-box.
4.  **📦 Xray / Nekobox / Exclave (JSON)** — Структура для классического ядра Xray.
5.  **🔗 Base64 Subscription** — Упаковывает все ваши серверы в зашифрованную подписку. Просто сохраните этот текст в файл на GitHub и используйте как ссылку в v2rayNG или Shadowrocket!

## 🛠 Система шаблонов (Только для YAML)

При экспорте в FlClash вы можете выбрать уровень маршрутизации:
* **💎 Крымский профиль (Ultimate v77.0):** Продвинутая база правил. Включает обход блокировок, прямую маршрутизацию для RU-сегмента (Госуслуги, Банки, ВК, Яндекс), защиту от фишинга (Hagezi/Sukka) и авто-выбор самого быстрого прокси.
* **⚡ Базовый профиль:** Легкий конфиг-пустышка без блокировщиков рекламы. Идеально для слабых устройств.
* **⚙️ Свой шаблон (Custom):** Вставьте любой чужой YAML-код, добавьте метки `{{PROXIES_YAML}}` и `{{PROXY_NAMES}}`, и скрипт сам встроит ваши серверы в этот конфиг.

## 🚀 Как использовать

1. Откройте [страницу конвертера](https://jinxpil.github.io/flclash-converter/).
2. Вставьте ссылки или JSON код в верхнее поле (или перетащите файл).
3. Нажмите **«► ДОБАВИТЬ И РАСПОЗНАТЬ УЗЛЫ»**.
4. (Опционально) Нажмите **«🌍 Флаги»**, **«⚡ Ping All»** и **«🧹 Удалить мертвые»**.
5. Выберите нужный формат экспорта из выпадающего меню.
6. Нажмите **«⬇ СКАЧАТЬ ФАЙЛ»** или скопируйте код в буфер обмена.
