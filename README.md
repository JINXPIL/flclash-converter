# ⚡ FlClash Network Builder

Универсальный веб-инструмент для парсинга сырых сетевых конфигураций (Sing-box, v2ray) и генерации стандартизированного YAML-профиля для ядра **Mihomo (Clash)** и клиента **FlClash**.

🌐 **[Запустить веб-интерфейс онлайн](https://JINXPIL.github.io/flclash-converter/)**

---

## 🧐 Архитектурная совместимость
Многие современные сетевые клиенты используют ядро *sing-box* и обмениваются конфигурациями узлов в формате JSON или через массивы Base64. Клиент **FlClash** (на базе ядра Mihomo) требует строгой YAML-разметки. 

Инструмент решает проблему несовместимости: он парсит массивы данных и корректно переносит критичные параметры протоколов (такие как `flow`, `client-fingerprint`, опции Reality), предотвращая ошибки `context deadline exceeded` (Timeout) при ручном переносе узлов. Сгенерированные узлы автоматически интегрируются в комплексный профиль маршрутизации.

## ✨ Ключевые возможности
- **Client-Side обработка:** Вся логика выполняется локально в вашем браузере (HTML/JS/CSS). Данные не отправляются на сторонние серверы.
- **Универсальный парсер:** Распознает прямые ссылки (`vless://`, `vmess://`, `trojan://`), зашифрованный Base64 и структуру `Sing-box JSON` (массивы `outbounds`).
- **Продвинутый экстрактор:** Корректно извлекает параметры: `uuid`, `pbk`, `sid`, `sni`, `flow`, `fp`, обеспечивая стабильность соединений с узлами.
- **Интерактивная сетка узлов (Nodes Grid):** Визуальный интерфейс для управления серверами. Возможность удалять (❌) нерабочие узлы и переименовывать их прямо в карточках.
- **Балансировка (Shuffle):** Встроенная функция алгоритмического перемешивания узлов (🔀) для более равномерного распределения нагрузки в итоговом конфиге.
- **Smart Inject:** Интеллектуальная сборка выбранных узлов с эталонным YAML-конфигом (содержит оптимизированные настройки DNS и правила маршрутизации Direct/Proxy).
- **Обратный экспорт:** Кнопка (🔗) на каждой карточке позволяет скопировать `vless://` ссылку конкретного узла для быстрой передачи на другие устройства.
- **Сохранение сессии:** Благодаря `localStorage`, браузер запоминает добавленные узлы даже после закрытия вкладки.

## 🚀 Как использовать?
1. Откройте [веб-интерфейс конвертера](https://JINXPIL.github.io/flclash-converter/).
2. Вставьте в текстовое поле конфигурационные данные в любом поддерживаемом формате:
   * URL-ссылку на удаленный список узлов (`https://...`)
   * Скопированный массив `Sing-box JSON`.
   * Сырой Base64-код или список ссылок.
3. Нажмите **«BUILD CONFIG»**.
4. В появившейся сетке карточек настройте узлы: удалите лишние, переименуйте их или перемешайте кнопкой **Shuffle**.
5. Нажмите **«DOWNLOAD»** для скачивания готового `.yaml` файла или **«COPY YAML»** для копирования кода в буфер обмена.
6. Импортируйте полученный профиль в клиент FlClash (раздел *Профили -> Новый профиль*).
