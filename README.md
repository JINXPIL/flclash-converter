# ⚡ Network Builder Omni-Core (FlClash / Xray / Sing-box)

**Network Builder** — это ультимативный, 100% локальный веб-инструмент для управления, тестирования и конвертации прокси-серверов. 

Он позволяет собрать ваши узлы из разных источников (разрозненные ссылки, Base64-подписки, чужие JSON-конфиги) и в один клик сгенерировать идеальный профиль маршрутизации для **FlClash**, **Nekobox (Xray)** или **Sing-box**.

## 🔥 Главные фичи

* 🛡️ **100% Локально и Безопасно:** Вся обработка, расшифровка Base64 и пинг происходят прямо в вашем браузере. Никаких бэкендов, скрытых серверов и утечек ваших приватных ключей. Работает даже без интернета (в офлайне) после загрузки страницы.
* 📦 **Omni-Парсер (Реверс-инжиниринг):** Скрипт умеет «распаковывать» готовые JSON-конфиги Xray/Sing-box, вытаскивая из них серверы (включая ключи Reality и SNI) и превращая их обратно в редактируемые карточки.
* ✏️ **Mass Editor (Массовое редактирование):** Выделите галочками нужные VLESS/Trojan узлы и измените им всем `SNI`, `Fingerprint` или `Flow` в один клик.
* 🧹 **Умная очистка и Дедупликация:** Автоматическое удаление мертвых серверов после пинга и очистка дубликатов по IP/Порту (скрипт оставит сервер с наименьшим пингом).
* 🏳️‍🌈 **Geo-Tags:** Автоматическое определение страны сервера и добавление красивых флагов в название.
* 📱 **PWA Ready:** Можно установить на главный экран смартфона как полноценное нативное приложение.

## 🔌 Поддерживаемые протоколы
Конвертер автоматически распознает ссылки и подписки следующих форматов:
`VLESS` (включая Reality/Vision) • `VMess` • `Trojan` • `Hysteria2` • `Shadowsocks (SS)` • `ShadowsocksR (SSR)` • `WireGuard` • `TUIC` • `Socks5` • `HTTP` • `SSH` • `NaiveProxy`

## 📤 Форматы экспорта

Вы можете выгрузить ваши узлы в 4 разных форматах:
1. **📱 FlClash YAML (TUN)** — Готовый профиль для мобильных устройств и ПК с включенным TUN-интерфейсом. Включает оптимизированные правила маршрутизации (обход блокировок, прямой доступ к RU-сегменту, банкам и госуслугам).
2. **🌐 FlClash YAML (Router)** — Профиль для домашних роутеров (Keenetic, OpenWRT) с отключенным TUN (работает через tproxy/redir).
3. **📦 Sing-box (JSON Outbound)** — Чистый массив `outbounds` для ядра Sing-box.
4. **📦 Exclave / Nekobox (Xray JSON)** — Готовый рабочий конфиг для Xray Core со встроенным балансировщиком (`proxy-balancer`) и проверками доступности (`burstObservatory`).
5. **⎘ Base64 Подписка** — Генерация локальной ссылки-подписки для вставки напрямую в клиенты.

## 🛠️ Кастомные YAML-шаблоны

Если вам не подходят встроенные правила маршрутизации, вы можете использовать режим **«Свой шаблон (Custom)»**. 
Вставьте любой свой YAML-код в открывшееся окно и добавьте в нужные места две переменные:

* `{{PROXIES_YAML}}` — сюда скрипт вставит физические настройки серверов.
* `{{PROXY_NAMES}}` — сюда скрипт вставит список имен серверов (для proxy-groups).

**Пример кастомного шаблона:**
```yaml
mode: rule
allow-lan: true
mixed-port: 7890

# Сюда встанут узлы
{{PROXIES_YAML}}

proxy-groups:
  - name: "Proxy"
    type: select
    proxies:
      - "Auto"
{{PROXY_NAMES}} # Сюда встанут их имена
