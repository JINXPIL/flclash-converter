### 🔥 Что нового в версии 17.02 ULTRA?

* 🚀 **Extreme Parser Engine:** Полная оптимизация кода для работы с **10,000+ узлами** одновременно. Плавный интерфейс даже при гигантских объемах данных.
* 🌍 **ULTRA Localization:** Глубокая поддержка 6 языков (RU, EN, ZH, FA, ES).
* 🛡️ **Система QuotaGuard:** Интеллектуальная защита от переполнения памяти браузера.
* 🧠 **Smart Duplicate Filter:** Автоматическое удаление дубликатов серверов по паре `IP:Port`.
* 🛠️ **Refined Diagnostics:** Обновленный логгер событий и исправление ошибок синтаксиса.

### 🎯 Конфигурации и маршрутизация (Пресеты)

Чтобы не засорять страницу портянками кода, все готовые пресеты вынесены в отдельные файлы репозитория.

* 🌐 **Раздельное туннелирование для Happ** — Оптимизированный пресет правил (Крым, локальные сети университетов, обход ограничений, AdBlock), собранный через конструктор `routing.happ.su`. Предназначен **строго** для клиента Happ.
    * 📄 Ссылка на файл конфигурации: [`./rus_vp_happ.json`](./rus_vp_happ.json)
* 🛠️ **Оптимизированный YAML-конфиг (Mihomo/Clash)** — v79.0 Ultimate со строгими TLS-отпечатками и защитой от DPI.
    * 📄 Ссылка на файл конфигурации: [`./GL_Crimea_ipv6_yan(9.35).yml`](./GL_Crimea_ipv6_yan(9.35).yml)
