# ⚡ FlClash VPN Converter

Простой и быстрый веб-инструмент для конвертации сырых VPN-ссылок и подписок (Happ, 2RayTun) в готовый YAML-конфиг для ядра **Mihomo (Clash)** и клиента **FlClash**.

🌐 **[Попробовать конвертер онлайн](https://ТВОЙ_НИК.github.io/flclash-converter/)**

---

## 🧐 В чём проблема и как мы её решаем?
Многие клиенты (например, Happ или 2RayTun) работают на базе ядра *sing-box* и распространяют конфигурации в формате JSON или зашифрованном Base64. Клиент **FlClash** (ядро Mihomo) требует строгой разметки в формате **YAML**. 

Этот конвертер работает прямо в браузере, парсит сырые данные и генерирует правильный YAML-профиль, сохраняя критически важные параметры протокола Reality (например, `flow` и `client-fingerprint`), без которых ядро Mihomo сбрасывает соединение (Timeout).

## ✨ Фичи
- **Всё работает локально в браузере** (чистый HTML/JS/CSS).
- **Поддержка Base64** (автоматическая расшифровка скрытых подписок).
- **Парсинг VLESS** (вытягивает `uuid`, `pbk`, `sid`, `sni`, `flow`, `fp`).
- **Синтаксис Mihomo** (генерирует готовый блок `proxies:` для вставки).
- Обход блокировок CORS для прямых ссылок `https://...` (через публичный API).

## 🚀 Как использовать?
1. Открой [живую страницу проекта](https://ТВОЙ_НИК.github.io/flclash-converter/).
2. Вставь в поле любой из вариантов:
   * Ссылку на подписку (начинается с `https://...`)
   * Скопированный зашифрованный Base64-код со страницы подписки.
   * Список серверов `vless://...` напрямую из другого приложения.
3. Нажми **«Конвертировать»**.
4. Скопируй полученный YAML.
5. Открой FlClash -> Профили -> Новый профиль (Текст) -> Вставь код и сохрани.
