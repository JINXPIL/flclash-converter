❓ Как это работает
  1. Установите INCY, если его ещё нет.
  2. Нажмите зелёную кнопку «Открыть в INCY».
  3. Подтвердите добавление профиля в приложении.

На компьютере с Windows приложение не получает профиль по кнопке: полная ссылка длиннее, чем Windows может передать программе. Поэтому там кнопка копирует профиль, а вы вставляете его в приложение из буфера обмена.

Профиль кэшируется на устройстве: если GitHub недоступен, страница возьмёт последнюю сохранённую версию.
